## The entry

> 404

A single number in digits and nothing else: the honest count of browser
tabs open. No words, no punctuation, no second number — just the count,
which says everything about the life behind it.

## How to run

Run `node main.ts` from the repository root. The program creates `/output`
if needed and writes the entry exactly, with no trailing newline, to
`/output/entry.txt`.
